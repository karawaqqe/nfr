# NFR — frontend магазина

## Запуск

```sh
npm install
npm run dev
```

Проверки: `npm test`, `npm run lint`, `npm run build`. Просмотр сборки: `npm run preview`.

React + Vite, JavaScript, React Router, CSS Modules, Lucide. TypeScript в исходниках не используется. Все маршруты собраны в `src/App.jsx`. Vercel использует `vercel.json` для прямого открытия страниц.

## Где что менять

- `src/data/products.js` — товары, категории, цены USD, варианты и остатки. Изображения подключены из `img/` через `new URL`, Vite включает их в сборку.
- `img/hoodie`, `img/tshirt`, `img/pants`, `img/rings`, `img/belt` — изображения коллекции. Для нового изображения добавьте путь в `photos` и привяжите ключ к товару.
- `src/components/ProductImage/` — общая заглушка с камерой и надписью NO PHOTO. Используется при отсутствии изображения и ошибке загрузки.
- `img/shoplogo.png` — исходный логотип пользователя, сохранён без изменений.
- `src/styles/variables.css` — палитра и отступы. `global.css` — общие элементы. Остальные стили находятся рядом с компонентами.
- `src/context/ShopProvider.jsx` — корзина и избранное. `src/utils/shop.js` — валидация корзины и фильтры.
- `src/data/info.js` — информационные тексты, FAQ и ограничения демо.

Фильтры каталога хранятся в URL (`q`, `min`, `max`, `size`, `sort`, `new`). Корзина различает ID, размер и цвет. Остаток сейчас демонстрационный и ограничивает каждый вариант. Хранилище проверяется при загрузке: неизвестные товары и варианты пропускаются. Недоступный localStorage не блокирует покупательский сценарий, но показывает предупреждение.

## Ограничения демо и подключение сервера

Checkout проверяет обязательные поля и формат индекса для Польши и Германии, не отправляет контакты и ничего не списывает. После подтверждения создаётся результат в памяти и очищается корзина. После перезагрузки подтверждение исчезает. Newsletter и официальные контакты пока не подключены; фиктивных адресов нет.

Перед продажами нужны реальные фотографии, составы и размерные таблицы, контакты продавца, юридические тексты, тарифы доставки и серверный учёт остатков по вариантам. На сервер нужно вынести источник цен, проверку наличия, создание заказа и интеграцию платежей с проверкой webhook. Нельзя доверять сумме или остаткам из браузера. Слой данных `src/data/products.js` следует заменить загрузкой из API с loading/error/retry состояниями; успешное оформление должно очищать корзину только после подтверждения сервером.

Сейчас каталог локальный и синхронный: искусственные загрузки и имитация сетевых ошибок не добавлены. Карточки используют отложенную загрузку изображений.
